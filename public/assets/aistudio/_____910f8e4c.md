## 〇、一页纸对齐（先读这个）



**一句话**：天然果实手作的娃娃，肚子里一张 NFC 标签——手机碰一碰，网页唤醒它的 MBTI 人格；现场自拍生成你的专属娃娃形象，打印机打印出参考形象，你亲手把它做出来。



**创意三件套**（缺一不可，开发永远优先保这三点）：

1. **碰一碰即聊**：零 App、零注册，NFC 一碰打开网页就能对话；

2. **专属形象**：自拍 → AI 生成独一无二的果壳娃娃形象，现场可看、可画、可带走；

3. **手作温度**：机器只做"生成与递送"，最后一步永远是观众的手。

    

**现场链路**：

```Plain Text
NFC 碰一碰 → 手机网页（人格对话，可随时进入）
展位流程：网页自拍/上传 → RDK X5 本地生成形象 → 形象卡展示
→ 机械臂执笔在纸上画出轮廓图纸（兜底：迷你热敏打印）
→ 机械臂抓取材料包递送（兜底：人工递）→ 观众手作
机器狗驮运材料包穿梭 + 巡游引流（氛围，不在关键路径）
```



**比赛硬约束**：

- 必须使用 RDK＋AI native，有可现场体验的硬件实物；

- 必交材料含「AI native 开发记录」：需求 → AI 辅助开发 → 人工检查修改 → 实机验证，至少一条完整链路留证据；

- 单人完整体验 ≤ 3 分钟；评审可访问代码（不要求公开）。

## 二、用户体验流程（含异常分支）



### 主流程 A：碰一碰对话（P0，独立可用）

1. 手机 NFC 碰娃娃 → 打开 `https://<域名或IP>/d/{dollId}`；

2. 落地页：娃娃形象、名字、MBTI 人格一句话简介，「开始聊天」按钮；

3. 对话页：流式对话，人格语气一致；对话中自然沉淀记忆（昵称、心情、约定）；

4. 再次碰一碰（或重开链接）：记得上次聊过什么。

    

**异常**：网络断开 → 页面缓存人格设定，提示"娃娃睡着了，连上网它就醒"；对话 API 超时 → 3 秒无响应给等待动画，10 秒失败给重试。



### 主流程 B：生成专属形象（P0，展位核心）

1. 从对话页或展位引导进入「创造我的娃娃」；

2. 自拍页：调用手机摄像头（`getUserMedia`），也允许从相册上传；

3. 上传至 RDK 本地服务 → 生成中页（进度动画 \+ 预期等待时间，目标 ≤40 秒）；

4. 形象卡页：展示生成结果，含娃娃名字、人格、关键词；可「再生成一次」（限 2 次，防排队拥堵）；

5. 「打印/绘制图纸」按钮：推送任务到机械臂绘图队列（或兜底打印机）；

6. 引导语：拿图纸去材料台，亲手做。

    

**异常**：摄像头权限被拒 → 引导用相册上传；生成失败 → 重试一次后改用预设 16 人格模板卡，体验不断；RDK 离线 → 一键切换云端 API（见降级方案）。



### 流程 C：记忆与广场（P2，赛后方向，现场只留入口）

- 形象卡页保留「上传我的娃娃」入口（占位，赛后开放）；

- 广场页可先做静态展示版（16 人格图鉴），不做实时社交。

## 三、页面清单



|\#|页面|路由|优先级|说明|
|---|---|---|---|---|
|1|娃娃落地页|`/d/{dollId}`|P0|NFC 直达；形象、人格、聊天入口|
|2|对话页|`/d/{dollId}/chat`|P0|流式对话、记忆沉淀、人格一致|
|3|自拍/上传页|`/create`|P0|摄像头 \+ 相册上传|
|4|生成中页|`/create/processing`|P0|进度与预期时间，可取消|

## 四、功能需求明细



### P0（12/5 前必须可用）

* [ ] NFC 落地页：`dollId` → 人格配置加载，16 人格可配（数据驱动，新增人格只加配置不改代码）；

* [ ] 流式对话：人格 Prompt 注入、上下文记忆（同 `dollId` 跨会话）；

* [ ] 记忆落库：关键信息抽取（称呼、事件、情绪），对话页可回看"娃娃记得的事"；

* [ ] 自拍上传：压缩后上传（≤2MB），保留拍摄时间；

* [ ] 形象生成：调 RDK 本地服务，返回图 \+ 人格关键词 \+ 名字；

* [ ] 形象卡：生成图 \+ 名字 \+ 人格 \+ 二维码（扫码可回到该卡，评委可验证）；

* [ ] 图纸任务下发：形象卡页按钮 → 绘图/打印任务入队；

* [ ] 降级开关：RDK ↔ 云端 API 切换（一个配置项，30 秒内可切）。

    

### P1（有就做）

* [ ] 16 人格图鉴静态页；

* [ ] 对话内容安全兜底（敏感词转场话术）；

* [ ] 体验计时提示（单人 3 分钟节奏提醒，现场运维看板）；

* [ ] 形象卡分享图（一键保存到相册，供观众发小红书）。

    

### P2（赛后，现场不做）

- 娃娃形象上传广场、线上碰一碰交友、订阅人格皮肤。

## 五、后端与接口（RDK X5 本地服务）



RDK 角色：**工位局域网内的本地服务器**，手机连工位 Wi\-Fi 访问。照片不出工位（隐私叙事点，路演必讲）。



### 服务部署

- RDK X5 上跑后端服务（建议 FastAPI/Node 均可，按队友技术栈定），工位路由器固定 IP；

- 网页静态资源可同机部署或 Vercel/对象存储 \+ 局域网 API 域名。

    

### API 草案

|方法|路径|说明|
|---|---|---|
|GET|`/api/dolls/{dollId}`|人格配置（名字、MBTI、开场白、形象图）|
|POST|`/api/dolls/{dollId}/chat`|流式对话（SSE），带会话记忆|
|GET|`/api/dolls/{dollId}/memory`|已沉淀记忆列表|
|POST|`/api/cards`|上传照片 → 创建生成任务，返回 `cardId`|
|GET|`/api/cards/{cardId}`|轮询生成状态/结果（图 URL、人格关键词、名字）|
|POST|`/api/cards/{cardId}/redraw`|再生成（每卡限 2 次）|
|POST|`/api/plot/jobs`|创建图纸任务（卡 ID \+ 纸型），返回队列位置|
|GET|`/api/health`|服务自查（模型、API Key、队列、磁盘）|



### 数据模型（简版）

```Plain Text
Doll { id, name, mbti, personaPrompt, avatarUrl, openingLine }
Memory { dollId, visitorKey, fact, createdAt }      // visitorKey 来自浏览器指纹/本地存储
Card { id, photoUrl, resultUrl, name, mbti, keywords, redrawCount, createdAt }
PlotJob { id, cardId, type: arm|printer, status, createdAt }
```

## 六、非功能需求



1. **性能预算**：自拍上传到形象卡 ≤40 秒；对话首 token ≤3 秒；单人全流程 ≤3 分钟。

2. **现场容错**：断网 → 对话页降级提示；RDK 挂 → 云端 API 切换开关；生成失败 → 16 人格模板兜底；机械臂挂 → 迷你热敏打印机兜底。

3. **隐私**：照片仅存工位本地，赛后删除；页面注明"照片不出这个房间"。

4. **兼容**：微信内置浏览器 \+ Safari \+ Chrome（iOS/Android 主流机型），NFC 拉起用 HTTPS 短链。

5. **并发**：同场最多按 5 人同时体验设计；生成任务排队 \+ 明确等待提示。

6. **可运维**：`/dev` 页显示服务状态、队列长度、当前模式（本地/云端），队友任何人 30 秒能判断现场健康度。

## 八、验收标准（与申报材料对齐）



1. 评委亲手碰一碰娃娃，**30 秒内**手机上弹出人格并开口对话；

2. 从自拍到看到专属形象卡 **≤40 秒**，成功率现场 ≥80%（失败走模板兜底也算体验完成）；

3. 图纸产出（机械臂画或打印）**≤90 秒/张**；

4. 断网、权限拒绝、生成失败三种异常现场演示不翻车；

5. 评审可通过二维码回看任一形象卡，验证数据真实落库。
